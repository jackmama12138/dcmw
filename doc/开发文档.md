# 资源管理准则 (Life-cycle Principle)：

    所有浏览器实例必须具备优雅关闭接口。

    必须处理好进程生命周期，严禁内存泄漏或产生“孤儿进程”。
# 分布式鲁棒性 (Distributed Robustness)：

    Worker 端必须实现心跳上报（Heartbeat），以便控制端监控状态。

    任务必须支持原子化处理，且在 Redis 中保持状态，支持失败后的断点续传。
